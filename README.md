# OcaVenteDz 🇩🇿

تطبيق OcaVenteDz لبيع وشراء المستعمل والجديد في الجزائر عبر كافة الـ 69 ولاية جزائرية مع تغطية شاملة لكافة البلديات.

## 🚀 المميزات الرئيسية:
- **تغطية شاملة لـ 69 ولاية جزائرية:** استعراض والبحث في كافة ولايات الوطن مع بلدياتها.
- **انشر إعلانك بكل بساطة:** نشر وتعديل إعلانات السيارات، الهواتف، العقارات، الأثاث وغيرها في ثوانٍ.
- **تسجيل مرن:** إمكانية التسجيل بالاسم ورقم الهاتف والولاية مع جعل البريد الإلكتروني اختيارياً.
- **محفظة وشحن CCP:** نظام محفظة متكامل يدعم طلبات الشحن عبر حساب البريد الجاري (CCP) المعتمد مع إرفاق وصل الدفع للتحقق اليدوي من الإدارة.
- **لوحة تحكم إدارية مدمجة:** مراجعة وقبول/رفض طلبات الشحن، متابعة النشاط والإحصائيات.
- **تكامل سحابي جاهز مع Back4App:** دعم المزامنة والنسخ السحابي مع Back4App Parse REST API.
- **واجهة مستخدم عصرية وأنيقة:** مصممة بأحدث معايير Jetpack Compose و Material Design 3 مع دعم كامل للغة العربية (RTL).

## 🛠️ التقنيات المستخدمة:
- Kotlin
- Jetpack Compose + Material 3
- Retrofit & OkHttp
- Kotlin Coroutines & Flow
- Robolectric Unit Testing
